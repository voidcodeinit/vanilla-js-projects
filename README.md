# Vanilla JavaScript Projects

A collection of small frontend projects and exercises built with **HTML, CSS, and Vanilla JavaScript**.

This repository is organized as a learning and portfolio collection, covering DOM manipulation, UI interactions, APIs, modules, local storage, filtering, pagination, and larger multi-page projects.

## 🚀 Getting Started

No build step is required for most projects.

1. Clone the repository.
2. Open the desired `.html` file with a local development server.
3. For projects using ES modules or API requests, use a local server such as VS Code Live Server.
